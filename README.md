Aim Trainer — простой тренажер прицела прямо в браузере для разминки реакции и точности. Тут 5 разных режимов: классика, ускорение, на время, мелкие мишени и игра без промахов. Запускается проще некуда: просто качаешь файл aim.html и открываешь его в любом браузере, ничего устанавливать и настраивать не надо.
