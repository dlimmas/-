# -
стартап
1. Название
Anchor
2. Смысл
Приложение для небольших групп людей (семья, друзья, команда), где главный фокус — совместные планы и расписание, но сделано так, чтобы было максимально просто договариваться и не терять договорённости.
3. Функции
•  Закрытые группы (круги)
•  Общий календарь с удобным предложением времени
•  Умный поиск свободных слотов у всех участников
•  Быстрое голосование «когда всем удобно»
•  Мини-чат, привязанный к конкретному событию
•  Напоминания и статус участия («точно приду / под вопросом / не смогу»)
•  История встреч и коротких итогов («о чём договорились»)
Чем отличается от обычных календарей
Обычные календари просто показывают даты.
Anchor помогает именно договориться:
•  сам предлагает удобные окна
•  собирает ответы
•  фиксирует результат
•  напоминает перед встречей
